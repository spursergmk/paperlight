Paperlight · 安装与首次打开
============================

macOS（.dmg）
  1. 双击打开 Paperlight-<版本>-mac-universal.dmg
  2. 把 Paperlight 拖进「应用程序」
  3. 第一次打开：在「应用程序」里对着 Paperlight 右键 →「打开」→ 再点「打开」
     （作者没有购买 Apple 开发者证书，系统会提示「无法验证开发者」，确认一次即可）
     如果系统直接提示「已损坏，无法打开」，打开「终端」执行：
         xattr -dr com.apple.quarantine /Applications/Paperlight.app
     然后重新打开。
  4. 需要 macOS 13 或更高版本；同一个包同时支持 M 系与 Intel 芯片。

Windows（.exe / .zip）
  1. 双击 Paperlight-<版本>-windows-x64-setup.exe，按提示安装。
  2. 第一次运行若出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。

Linux（.AppImage / .deb）
  AppImage：chmod +x Paperlight-*.AppImage && ./Paperlight-*.AppImage
  deb：     sudo apt install ./Paperlight-*.deb

开始使用
  · 点左上角「打开文件夹」，选一个放 PDF 的文件夹，双击 PDF 就在新标签页打开；
    也可以把 PDF 直接拖进窗口，或按 ⌘/Ctrl+O 选择文件。
  · 拖动阅读区与右侧「阅读助手」之间的分界线，可以随时调整两边宽度（双击复位）。
  · 关闭时会记住打开的标签页、文件夹和每本书的阅读位置，下次启动自动恢复。

关于 AI 功能
  「义项」「追问」「整句翻译」需要填自己的 API key：
  右上角「模拟翻译」→「OpenAI 兼容 API」→ 选择服务并粘贴 key → 保存。
  密钥只写入你自己的电脑，不会上传到任何服务器；不填 key 也可以使用「模拟翻译」模式。
